  3. Configure OAuth Consent Screen (User Type: External, App Name: Academic Tracker).
  4. Go to Credentials → Create Credentials → OAuth Client ID (Web application).
  5. Add your GitHub Pages URL to Authorized JavaScript origins (e.g. https://<username>.github.io).
  6. Copy your Client ID and paste it below.
